### Obtener detalles de una cuenta

Obtiene los detalles de la cuenta actual.

<RequestExample>

``` filename
GET /api/v1/accounts/{id}
```

</RequestExample>

### GET

```
/api/v1/accounts/{id}
```

---

## Autorizaciones

### api_access_token

**Tipo:** string (header requerido)

Este token puede obtenerse desde la página de perfil del usuario o mediante la consola de Rails.\
Proporciona acceso a los endpoints según el nivel de permisos del usuario.

Este token puede ser almacenado por un sistema externo cuando el usuario es creado vía API, para realizar acciones en nombre del usuario.

---

## Parámetros de Ruta

### account_id

**Tipo:** integer (requerido)\
El ID numérico de la cuenta.

---

## Respuesta

### 200 – application/json

**Éxito**

---

### Campos de respuesta

**id**\
number\
ID de la cuenta.

**name**\
string\
Nombre de la cuenta.

**locale**\
string\
Configuración regional (idioma/locale) de la cuenta.

**domain**\
string\
Dominio asociado a la cuenta.

**support_email**\
string\
Correo electrónico de soporte de la cuenta.

**status**\
string\
Estado actual de la cuenta.

**created_at**\
string (date-time)\
Fecha de creación de la cuenta.

**cache_keys**\
object\
Claves de caché asociadas a la cuenta.

**features**\
string[]\
Funciones habilitadas para la cuenta.

**settings**\
object\
Configuraciones de la cuenta.

**custom_attributes**\
object\
Atributos personalizados de la cuenta.

**latest_bluechat_version**\
string\
Última versión disponible de Bluechat.

Ejemplo:

```
"3.0.0"
```

**subscribed_features**\
string[]\
Lista de funcionalidades empresariales suscritas (si la edición enterprise está habilitada).
